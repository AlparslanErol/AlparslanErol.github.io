# Alparslan Erol — Personal Website

Personal site for **Alparslan Erol**, built with Astro and Tailwind CSS and intended for GitHub Pages at `https://alparslanerol.github.io`.

## Local development

Requires Node.js 22.12+ per current Astro documentation.

```bash
npm install
npm run dev
```

Build locally:

```bash
npm run check
npm run build
npm run preview
```

## GitHub Pages

Create/keep the repository named exactly:

```text
AlparslanErol.github.io
```

Then set **Settings → Pages → Source → GitHub Actions**. GitHub supports custom workflows using `configure-pages`, `upload-pages-artifact`, and `deploy-pages`.
